# Mental Health Application

## Overview

A comprehensive mental health platform designed to connect and support **patients, parents, doctors, and administrators** through an integrated digital ecosystem.

The platform allows patients to access mental health services, enables parents to monitor their children's well-being, and provides doctors with tools to manage and follow up with patients. An administrative web platform was also developed to provide administrators with centralized control, monitoring, analytics, and insights into the application.

## My Contribution

I was responsible for the **front-end development of the web-based Admin Dashboard**.

While the mobile application provides the main experience for patients, parents, and doctors, my role focused on building the **administrative web platform** used to monitor and manage the application.

### Key Responsibilities

* Developed the **Admin Dashboard frontend** for managing and monitoring the platform.
* Integrated the frontend with the **backend APIs** to retrieve, display, and manage application data.
* Built **analytics dashboards and data visualizations** to provide administrators with meaningful insights.
* Implemented functionality for administrators to **monitor users and manage application data**.
* Created responsive and user-friendly interfaces for efficient administration.
* Collaborated with the backend to ensure reliable **API integration and data flow**.
* Translated application requirements into functional and intuitive administrative interfaces.

## Main Features

### Admin Dashboard

* Centralized overview of application activity
* User monitoring and management
* Data management
* Analytics and statistics
* Insights and data visualization
* Integration with backend services through APIs

### User Roles

The overall platform supports multiple types of users:

* **Patients** — Access mental health services and manage their information.
* **Parents** — Monitor and follow their children's mental health activity.
* **Doctors** — Manage and monitor their patients.
* **Administrators** — Monitor and manage the platform through the web-based Admin Dashboard.
